# **queue-ticket-managment**

## **Como utilizar:**

> O gerenciador de fila é separado em três paginas:
>
> > Monitor: Exibe duas senhas(a ultima e a penultima) e seus respectivos guichês;
>
> > Admin: Utilizado pelo guichê, usado para chamar a proxima senha;
>
> > Config: Configurações do aplicativo.
>
> OBS: Para utilizar o som de notificação, entre nas **configurações da pagina** e clique em **permitir** nas opções de Som.

## **Tecnologias utilizadas:**

```
Javascript
Vue
Vue-Router
Vuex
Axios
ExpressJS
Socket.IO
Cors
Nodemon
```

## **Project setup:**

```
cd client > npm install

cd server > npm install
```

### Compiles and hot-reloads for development

```
cd client > npm run serve

cd server > nodemon server.js
```

### Compiles and minifies for production

```
npm run build
```

### Lints and fixes files

```
npm run lint
```
